# Assign Tasks board

- **Intent:** Give supervisors and admins a Kanban-style view for assigning tasks by team member.
- **Behavior:** Add an Assign Tasks tab inside each project workspace. Each member of that project has a column, plus an “ยังไม่มอบหมาย” column. Creating a task from this tab leaves its assignee blank. Dragging a task between columns updates its assignee; task status remains unchanged.
- **Access:** Supervisors and admins can use the board. Staff keep the existing task views and cannot reassign tasks from this page.
- **Compatibility:** Keep the existing status-based project Kanban unchanged. Use existing project visibility, assignable-member lists, task edit permissions, and workspace update flow.
- **Not included:** Cross-project assignment or status changes from this board.
